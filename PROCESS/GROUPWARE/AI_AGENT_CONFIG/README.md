# 🤖 AI_AGENT_CONFIG — Groupware Agent Configuration Hub

Thư mục này chứa toàn bộ cấu hình, bộ nhớ đệm L1 và quy tắc vận hành cho AI Agent khi tác nghiệp trong hệ sinh thái **Groupware Vinatech**:

1. **`GW_FORM_MATRIX.json`:** Bộ nhớ đệm L1 phản hồi tức thì (<0.001s) chứa thông tin 17 biểu mẫu, bảng CSDL, quan hệ ERP/MES và lỗi thường gặp.
2. **`APPROVAL_LINE_MATRIX.json`:** Bản đồ tuyến phê duyệt theo phòng ban, giá trị tiền tệ và pháp nhân.
3. **`RULES.md`:** 10 Quy tắc vàng bất biến khi truy vấn hoặc can thiệp hệ thống Groupware.
4. **`KNOWLEDGE.md`:** Cheat sheet nén gọn hỗ trợ nạp context cho Agent.
5. **`LESSONS_LEARNED.md`:** Tổng hợp bài học kinh nghiệm và sự cố thực tế.
